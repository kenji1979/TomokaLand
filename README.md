# TomokaLand

『ともかのくさいいき大ぼうけん』は、iPad Pro / iPhone 11 のブラウザで遊べる
2D横スクロールアクションゲームです。全3ステージを遊べます。

主人公「ともか」は、選んだ写真をそのまま顔として使う2頭身キャラクターです。
草原ステージを進み、ジャンプ踏みつけと口から吐くギャグ寄りの「くさい息」で敵を倒します。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 画面上の「写真」ボタンから主人公にしたい写真を選びます。
3. 「スタート」を押してゲーム開始です。
4. 各ステージのボスを倒してから、ゴールの旗まで進むとクリアです。

ローカルサーバーで確認する場合:

```sh
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開いてください。

## 操作

### iPhone / iPad

- 左下の `←` / `→`: 移動
- 右下の `ジャンプ`: ジャンプ
- 右下の `くさい息`: 口からくさい息を吐く

### PC

- `←` / `→` または `A` / `D`: 移動
- `Space`: ジャンプ
- `X` または `K`: くさい息

## ゲーム内容

- 主人公: 写真をそのまま使う2頭身の「ともか」
- ステージ:
  - 1-1 にこにこ草原
  - 1-2 おなら洞窟
  - 1-3 おかしの町
- 攻撃:
  - 敵を上から踏みつける
  - 口から緑色の「くさい息」を吐く
- パワーアップ:
  - ミントキャンディで一定時間くさい息の範囲と威力がアップ
  - にんにくでさらに長めのスーパーくさい息
- 敵:
  - くさむし
  - はなつまみ鳥
  - ガスマスクもぐら
  - ガススライム
  - こうもり
  - むし歯ばいきん
  - 各ステージのボス
- 音:
  - Web Audio APIでジャンプ、コイン、くさい息、ダメージ、クリア音を生成
  - ステージごとに違う簡易BGMを自動演奏

## 写真について

写真はブラウザ内で読み込まれ、ゲーム画面の描画にのみ使われます。
この静的版ではサーバーへアップロードしません。

子どもの写真を使う場合は、公開URLに置かず、家庭内や確認用の環境で遊ぶことを推奨します。
